# Chivalry 2 Team Objective Tier List

This is the first scaffold of your website. It is a static version, which means you can open it directly in a browser without installing coding tools.

## How to open it

Open this file in your browser:

`C:\Users\biged\Documents\Chiv2TOlist\index.html`

## Admin controls

Scroll to the Admin section and use this first-version code:

`mason-order`

You can add players, edit players, delete players, move players up and down, filter the list, and export your saved data.

For now, changes are saved in your browser using local storage. That is perfect for testing the idea, but it is not a real online database yet.

## Good next steps

1. Replace the demo players with your first real player list.
2. Decide what fields matter: region, platform, role, clan, notes, recent form, or proof links.
3. Once the layout feels right, connect a real database and real admin login with Supabase.
4. Publish the site with Vercel so other people can view it.
